JDK version used "17.0.12" 2024-07-16 LTS


HelloWorld.java program prints the message "Hellow World" in the console.

The program is compiled using the command : javac HelloWorld.java, which then generates the HelloWorld.class file. 

This generated class file is then executed using the command : java HelloWorld, to print the message in the console.
