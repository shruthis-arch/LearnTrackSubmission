Description:

This is a Student and Course Management system, where we allow users to perform various operations like add, update, remove, view or find students and courses. It allows the students to enroll for a specific course and the enrollments for a student can be viewed, completed or cancelled. 

How to Compiler and run?

From the Main.java 
javac LearnTrack/src/com/airtribe/learntrack*.java to compile all the classes 
java LearnTrack/src/com/airtribe/learntrack/Main.java to run the application
